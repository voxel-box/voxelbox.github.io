how we run them

Hosted by us, not resold.

These servers sit on the same hardware and the same monitoring as our client work. The community servers are, in a very real sense, our test bench.

Our own panel

Servers run on a game panel we host ourselves, with live player tracking and history — not a reseller dashboard.

Monitored and backed up

Uptime probes and scheduled snapshots run on a timer. If a world goes down overnight, the alert reaches us before it reaches you.

Moderated properly

Clear rules, real moderators, and anti-grief tooling written for the server rather than bolted on from a plugin store.

Free, and staying free

No slots to buy, no priority queue, no cosmetics. The servers are funded by the studio, not by the players.
